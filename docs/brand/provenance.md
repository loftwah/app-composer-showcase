# Linkarooie identity and reference creator assets

MP explicitly requested the established Linkarooie identity and his own Loftwah profile. The reference creator images keep their configured filenames so the live owner settings keep resolving; the reviewed exports for this release replace the earlier photograph, banner and neon app mark, and their current bytes are recorded in the SHA-256 list below. No legacy modules, trackers, biography or hidden data execute or import. The Inter fonts come from the `loftwah/linkarooie-3` checkout at `149f277bc45baf31eca406878e8e16325b85a06f` and carry the included SIL Open Font License.

The lime dark/purple light wordmark and typography follow that established identity. Creator images are explicit owner configuration, empty by default. All creators use the same card/settings renderer; Loftwah is a separately configured reference creator.

Ink-line cel animation release, 17 October 2026. The hero illustration, the default social card, the app icon and the Linkarooie navigation crop moved to the reviewed App Composer ink-line cel animation set after the owner rejected the flat cut-paper treatment. `public/brand/linkarooie-art-v4-master.png` is the generated master `tile-linkarooie-v5-1.png` from fal.ai request `01a1490e-e9a6-76d1-85d7-f3f508ad5533`; its prompt, request identity and file inventory are recorded in the owning App Composer repository (`.artwork/tile-linkarooie-v5.json`, `.artwork/masters/tile-linkarooie-v5.result.json` and `public/brand/apps/provenance.json`). `mark.svg` is the refined authored family mark and `icon.png` is its 512px flat rendering, not generated or traced from a third-party mark. This release removed the rejected v3 cut-paper art and the v3 navigation crops; their bytes remain in git history. No third-party logo, vendor interface or personal image is used in the generated or authored app artwork.

`share-card.html` is the editable 1200 × 630 social-card layout. Replace its PORTRAIT token with the unchanged portrait data URL and render in Chromium to JPEG. The portrait is the original photograph, without generated facial changes. The discarded image-generator experiment was not published. The final card has no stale domain, private biography, invented badges or social platform dependence.

Version 1 settings files retain their original nine fields and preserve the new app-owned image/X configuration when applied; these files are not a full profile/media backup. Existing collection export also includes the image/X settings and all card grouping. Grouped discovery extends the existing cards and presentation rows; no second content store or migration is introduced.
