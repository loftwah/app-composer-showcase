The independent app and additions remain MIT. Existing original illustration/font assets retain their own adjacent provenance. The legacy Astro README declares MIT; no asset or source bytes from that repository were copied, so its missing standalone root licence is not used as permission for asset redistribution.

Implemented: optional handle, Website/GitHub/Bluesky/LinkedIn links, compact text links, fixed link symbols, pinned-first public order, server-canonical native sharing/copy/manual fallback. Owner studio and API preserve visibility and provider eligibility. Presentation uses an app-owned settings row; no schema migration or third-party tracking was added.

Artwork and discovery, reviewed 17 October 2026: the hero, default social card and app icon now come from the reviewed App Composer cut-paper set; `public/brand/linkarooie-art-v3.PROVENANCE.txt` records the request, files and removals, and `docs/brand/provenance.md` keeps the hashes. The fixed symbol set grew to eight (link, book, code, music, video, game, heart, star) so a Games row no longer borrows a favourite heart. Each profile section title carries the symbol of the group it names, using the same newly authored fixed geometry. Search and its count render only when more than one card is published, and the count stays silent until the visitor types or filters. The jump nav keeps one scrolling row on phones, and the phone hero is compressed so the first featured pick is reachable without scrolling past a tall banner. Only the loading behaviour, layout and authored marks changed: no card, visibility, provider or credential rule was relaxed, and no new storage, endpoint or dependency was introduced.

Deferred: optional uploaded avatar/banner, multi-profile/workspace ownership, directory inclusion, broader analytics and portable whole-profile JSON import. Existing private export includes effective profile settings and per-card presentation. These are not completed merely by the profile surface.

Achievements, reviewed 16 October 2026: the same pinned Astro `Achievement` shape supplies the title/description/date/link/icon reference; newly authored app-owned storage, bounded CRUD, explicit visibility, optimistic concurrency, owner preview/recovery and public list extend it. Only the type/behaviour was referenced; no personal milestone, hidden data, legacy module or asset was imported. The MIT Gregorian calendar helper was copied from App Composer `6fbd5cd6a038072481713b7f4af23ab40f7df9dd` (`lib/content-model/calendar-date.mjs`) into the app's independently owned `public/brand/achievement-date.mjs`, with year/month precision added here. Client preview and server rendering share that exact local helper. The owner export includes achievements; whole-profile import/recovery and multi-profile support remain deferred. Source tests are separate from browser and release acceptance.

Tags, reviewed 16 October 2026: the pinned Astro rich-tag shape and #25 supply the behaviour reference (optional explanation/citation/related work). The storage, text-only native disclosures, bounded HTTPS fields, escaped rendering, Escape/focus recovery and owner editor are newly authored in this independent MIT app; no legacy HTML interpolation, hover-only interaction, personal tag catalogue or remote preview is imported. Composer receives its own MIT copy of this app's pure field schema, never a runtime import or data dependency. The versioned collection reuses the existing exact-byte settings compare-and-swap used by milestones. Source tests are distinct from browser qualification, composition activation and production acceptance.
